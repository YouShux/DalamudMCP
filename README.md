# DalamudMCP

让支持 MCP 的 AI 客户端读取 FFXIV 游戏信息、截图、操作界面，并使用卫月内置调试工具。

## 使用

1. 在卫月的自定义插件仓库中添加以下地址：

   ```text
   https://raw.githubusercontent.com/YouShux/DalamudMCP/main/Pluginmaster.json
   ```

2. 在插件安装器中搜索并安装 `DalamudMCP`。
3. 输入 `/dalamudmcp` 打开设置，确认“服务运行中”。
4. 在 AI 客户端中添加 MCP，名称填 `DalamudMCP`，连接类型选 Streamable HTTP，地址填 `http://127.0.0.1:61016/mcp`。
5. 连接后直接向 AI 提问，例如“读取我的坐标”“查看背包”“截取当前游戏画面”。

- **读取信息**：角色、坐标、背包、任务、FATE、聊天和游戏窗口。
- **游戏操作**：在“设置”中开启“允许游戏交互”，可使用移动、传送、目标交互和界面操作。移动需要 vnavmesh；城内以太网需要支持传送 IPC 的 Omni，并启用“更好的传送管理”。传送请求接受后，可查询区域和坐标确认到达。
- **卫月调试**：在卫月设置中开启开发者模式，确认内置 MCP 端口与插件中的“卫月调试端口”一致，默认 `39217`。写入内存、调用函数等操作还需开启“允许底层调试”。

在“工具”页可单独启用或关闭每项工具。修改 MCP 端口后，同步更新 AI 客户端的连接地址。
